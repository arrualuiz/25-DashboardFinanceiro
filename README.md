# Pluggy Monitor

Coletor local para registrar dados financeiros visíveis no Meu Pluggy.

O projeto preserva as coletas brutas localmente e separa:

- Overview;
- Fluxo de Caixa;
- Ativos;
- status técnico das conexões.

Consulte [outputs/pluggy-monitor/README.md](outputs/pluggy-monitor/README.md) para executar.

## Histórico

As alterações devem ser registradas em commits. Os arquivos de sessão do Chrome e as coletas financeiras ficam fora do Git por segurança.
